### 阈值 3.0 试验的教训（已回退，保留记录）

床位形下曾将 min_peak_ratio 3.5→3.0 以求覆盖翻倍（26%→54%，精度不变）。段 4 修正判读暴露其代价：走动段"有效"窗升至 16%（挂起率 84%，**破 90% 验收线**）、离链站立段出现 12% 疑似有效窗。**教训：调灵敏度参数必须同时复检特异性指标**——3.0 已回退，注释留档于 dsp.py / csi_core.c。覆盖率问题的正解是用真实体动数据重标定功率门控（motion_k）+ 相干性选载波，而非单降峰值阈值。

## 4. 遗留项（按优先级）

1. **侧卧聚合失效（2026-10-05 晚补充定性）**：真值 7.7bpm 的呼吸成分在侧卧段**确实存在于约 7–10 个子载波**（峰突出度 0.94–1.00），但一个 10.0bpm 的非呼吸成分占据了 22/52 个子载波——跨子载波频率投票会被它带走（投票测试：侧卧段冠军 10.0bpm/22 票 vs 真值仅个位数票；仰卧段则 52/52 全票命中 9.1bpm）。候选对策（按性价比）：
   a. **时域相干性判别**：呼吸频率长时间稳定，干扰成分频率会漂移——滑窗跟踪峰频轨迹的稳定性而非单窗选举；
   b. **M3 深度模型**：学习"呼吸样"时频模式 vs 干扰（原计划内能力）；
   c. **双链交叉**（+¥40）：干扰大概率链路特异，双链互证；
   d. 长窗（60–90s）内谱线宽度判别（生理呼吸线窄、干扰偏宽）。
   **判定：算法可修的范畴，暂不需要为此加硬件**。
2. **有效窗覆盖率 54%**：已达标"趋势监测"定位（Serene 同类系统的中断特性），但离"连续监测"有距离；侧卧问题解决前难再提升。
3. **MQTT 上行 + 断网自治**：固件模块已写好未联调——需要 RX 连家里路由器 + broker（本地 amqtt 或 VPS）。完成即解除"RX 必须连电脑"限制，也是 M3 后端接入真实数据的前提。
4. 段 3 真值补报（可选，锦上添花）。
5. 段 4 门控复测（待一轮信号良好的采集）。
